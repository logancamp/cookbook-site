# Cookbook Webpage:
## Description:
This project was originally developed to act as an experiment on AI's coding abilities mixed with personal knowledge of software engineering to co-develop a cookbook webpage quickly for personal use. I later no longer needed the webpage and finished up an MVP for basic functionality. The code itself works fairly well but is clunky and not architecturally sound. Will need refactored for any future expansion.
<br><br>

## Instructions:
Clone and open the HTML file. <br>

## Features:
- Add recipes
- Add sub-recipes
- View recipes and sub-recipes
- Drag to organize recupe hierarchies
- Searchable recipes
- Categorization and filtering
- Recently Deleted with restore and delete functionality
- Local storage (no online or saved backup, items may not consistently save long term)
